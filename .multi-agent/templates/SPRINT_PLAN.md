## 5. 并行协作规则

- 每个 agent 只处理自己任务卡中列出的文件或路径。
- 多个 agent 不应同时修改同一文件；如不可避免，先拆分所有权或安排顺序。
- 共享约定、接口、模板字段发生变化时，必须在本文件的“变更记录”中登记。
- 阻塞超过一个工作周期时，任务负责人必须说明原因和建议处理方式。
