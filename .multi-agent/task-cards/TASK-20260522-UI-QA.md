## Review Checklist

- [ ] Navigation works on mobile.
- [ ] Page hierarchy is clear: Dashboard -> Briefing / Articles -> Trends / Archives -> Sources / Alerts.
- [ ] No new heavy UI/chart dependency.
- [ ] No backend API contract change.
- [ ] No new English UI copy unless it is a brand/technical label.

- [ ] Dark mode remains readable.
