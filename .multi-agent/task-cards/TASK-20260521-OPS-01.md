# TASK-20260521-OPS-01: RSS 源健康清单 v2

## Task Info

- Type: 运营 / 数据治理
- Priority: P1
- Status: TODO
- Owner: Codex · Test Skill
- Sprint: S2 · M3.5（与 S1 并行）

## Goal

清理 `REVIEW.md` 中"Tier-0 RSS 多源失败"风险：

1. 从本地网络批量探测所有 enabled 源的可达性 + 解析有效性
2. 输出健康报告（成功 / 超时 / 解析失败 / 重定向）
3. 在 seeds 中标记失败源 `enabled: false`（保留 URL，不删）
4. 给老板一份 markdown 报告

## Scope

### Allowed Changes

| Path | Purpose |
| --- | --- |
| `docs/operations/rss-health-2026-05.md` | **新建** 健康报告 |
| `seeds/**` | **只能** 修改 `enabled` 字段；不允许新增/删除条目 |
| `scripts/probe-rss-health.py` | 新建探测脚本（如不存在） |
| `REVIEW.md` | 关闭"Tier-0 RSS 多源失败"条 |

### Forbidden

- 添加新源（属于 Backend Skill，不是 Ops）
- 修改 `backend/**`、`workers/**`
- 删除 seeds 中任何条目

## Validation

```bash
python scripts/probe-rss-health.py --concurrency 10 --timeout 20 \
  --out docs/operations/rss-health-2026-05.md

# 报告必须包含：
#  - 总数 / OK / 超时 / 解析失败 / HTTP 4xx / HTTP 5xx
#  - 每个失败源：URL、错误类型、最近一次成功时间（如有）
#  - 建议禁用清单（已应用到 seeds.enabled=false）
```

## Risks

- 网络抖动导致误判：每个失败源探测 2 次，2 次都失败才标记
- 商业代理：本机若无代理，标记需注释"localnet"，老板可在 prod 重测
