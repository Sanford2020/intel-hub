## Decisions Inherited from ADR-03

- JWT HS256，httpOnly cookie + CSRF 双提交
- Bcrypt rounds=12，密码 ≥ 12 字符
- 多租户列：所有业务表迁移加 `tenant_id VARCHAR(64) NOT NULL DEFAULT 'default'` + 单列索引
- 公开白名单：`/health`, `/ping`, `/docs`, `/openapi.json`, `/auth/{login,refresh,logout}`
- Refresh 黑名单使用 Redis SET，key 前缀 `jwt:revoked:`，TTL = refresh 剩余寿命

## Validation

```bash
cd backend && PYTHONPATH=/workspace alembic upgrade head
# users + auth_events 表 + 全业务表 tenant_id 已落地

# 启动 backend，env 内置 admin
AUTH_BOOTSTRAP_ADMIN_EMAIL=admin@example.com \
AUTH_BOOTSTRAP_ADMIN_PASSWORD=StrongPass1234 \
uvicorn backend.app.main:app --reload

# 登录
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin@example.com","password":"StrongPass1234"}'
# → 200 + Set-Cookie: access_token, refresh_token + JSON {csrf_token, user}

# 当前用户
curl -b cookies.txt http://localhost:8000/api/v1/auth/me
# → 200 {email, role:'admin', tenant_id:'default'}

# 刷新
curl -X POST -b cookies.txt http://localhost:8000/api/v1/auth/refresh
# → 200 + 新 Set-Cookie

# 登出
curl -X POST -b cookies.txt -H 'X-CSRF-Token: <csrf>' http://localhost:8000/api/v1/auth/logout
# → 204；再访问 /auth/me → 401
```

## Risks

- bcrypt 在 CI 慢：测试用 rounds=4（env override），prod 12
- 启动钩子并发：bootstrap admin 用 `INSERT ... ON CONFLICT DO NOTHING`
- alembic 多表加列在大表上锁：默认 `'default'` + NOT NULL 在 PG 14+ 是 fast，但记录 REVIEW 风险
