# Product Skill

## 职责

- 澄清用户目标与 MVP 边界
- 维护/更新 `docs/prd.md`
- 定义验收标准与用户场景
- 将需求转化为 TASK（Goal、Scope、优先级）

## 输入

- 用户描述、现有 `docs/prd.md`、`PROJECT_BRIEF.md`（若存在）

## 输出

- PRD 章节更新建议
- TASK 草稿（不含实现细节）
- Out of Scope 明确列表

## 禁止

- 不直接改业务代码
- 不决定底层技术选型（交 Architecture Skill + ADR）

## 启动语

```
Product Skill：基于 docs/prd.md 为 [功能描述] 写 TASK 草稿，含 Goal、验收标准、Out of Scope。不改代码。
```
