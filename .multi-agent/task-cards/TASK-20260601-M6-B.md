## RBAC 矩阵（从 ADR-03 §4）

| 端点族 | admin | analyst | viewer |
|--------|-------|---------|--------|
| GET sources/articles/archives/briefing/stats | ✅ | ✅ | ✅ |
| POST/PUT/DELETE sources | ✅ | ✅ | ❌ |
| POST sources/{id}/ingest | ✅ | ✅ | ❌ |
| POST/PUT/DELETE alerts | ✅ | ✅ | ❌ |
| DELETE articles/intelligence_reports | ✅ | ❌ | ❌ |
| GET/POST /users | ✅ | ❌ | ❌ |
| POST /ai/*（手动重分析） | ✅ | ✅ | ❌ |

封装为 `require_role('admin')` / `require_role_any('admin','analyst')` 装饰器或依赖。

## Validation

```bash
# 用 viewer 试 DELETE → 403
curl -X DELETE -b viewer-cookies.txt http://localhost:8000/api/v1/sources/1
# → 403

# 用 analyst 试 POST source → 200
curl -X POST -b analyst-cookies.txt -H 'X-CSRF-Token: ...' \
  http://localhost:8000/api/v1/sources -d '...'
# → 200

# tenant 隔离：tenant=B 用户查 tenant=A 创建的 source
# → 404（不泄露存在性）

# 公开白名单
curl http://localhost:8000/api/v1/health   # 200
curl http://localhost:8000/api/v1/articles # 401（除非 AUTH_BRIEFING_PUBLIC）
```

- 现有 pytest 全挂：M6-D 卡负责重建测试 fixtures（auth headers）；本卡不修测试，但要保证业务逻辑不变
