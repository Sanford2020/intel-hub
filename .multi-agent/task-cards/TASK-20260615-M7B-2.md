## UX 规范

1. **Step 1 环境检测**：调 `/setup/status`；DB/Redis 任一红 → 显示运维提示 + 重试按钮，不让继续
2. **Step 2 env 配置**：表单含 `OPENAI_API_KEY`（password input + "可跳过，走 mock 模式" 提示）、`FEISHU_WEBHOOK_URL`（可选）；提交后 toast"已写入 backend/.env"
3. **Step 3 seed 选择**：复选框列出 seeds 目录文件名（接口返回），默认勾 `bestblogs-sources` + `osint-rss-sources`
4. **Step 4 管理员**：email + password (≥ 12 字符) + 确认密码；提交成功跳 `/login`
5. **打不开**：已 setup → 顶部黄条"系统已初始化"，3 秒后跳 `/login`
