## Goal

按 ADR-05 实现一次性 Setup Wizard API：状态检测、写 env、跑 seeds、bootstrap admin、触发首日简报。**全部仅在 users 表空时开放。**

## Scope

### Allowed Changes

| Path | Purpose |
| --- | --- |
| `backend/app/modules/setup/__init__.py` | 新模块 |
| `backend/app/modules/setup/router.py` | `GET /setup/status` `POST /setup/env` `POST /setup/seed` `POST /setup/bootstrap-admin` `POST /setup/trigger-briefing` |
| `backend/app/modules/setup/service.py` | 检查 DB/Redis、写 `backend/.env`（chmod 600）、运行 seeds、调 auth.bootstrap_admin、调 archive task |
| `backend/app/modules/setup/guards.py` | dependency: 拒绝已 setup 系统 |
| `backend/app/models/system_settings.py` | 新表（k/v + setup_completed_at） |
| `backend/alembic/versions/*setup*.py` | 迁移 |
| `backend/app/api/v1/api.py` | include_router('/setup')，公开路由（白名单加 `/setup/*`） |
| `docs/api.md` | §Setup Wizard |

### Forbidden

- `apps/web/**`（B-2 卡）
- 真改 `backend/app/main.py` 启动逻辑（写 env 后用户手动重启）
- 默认 admin 凭据（ADR-03 严禁）

## Validation

```bash
# fresh DB (users empty)
curl http://localhost:8000/api/v1/setup/status
# → 200 {"setup_completed": false, "db_ok": true, "redis_ok": true, "openai_configured": false}

curl -X POST http://localhost:8000/api/v1/setup/env -d '{"OPENAI_API_KEY":"sk-xxx","FEISHU_WEBHOOK_URL":""}'
# → 200，backend/.env 被更新且 chmod 600

curl -X POST http://localhost:8000/api/v1/setup/seed -d '{"sets":["osint-rss-sources","bestblogs-sources"]}'
# → 200 + 数量

curl -X POST http://localhost:8000/api/v1/setup/bootstrap-admin -d '{"email":"me@x.com","password":"StrongPass1234"}'
# → 201；users 表有 1 行 admin；system_settings.setup_completed_at 已写

# 再访问 setup → 403
curl http://localhost:8000/api/v1/setup/status
# → 403
```

## Risks

- 写 `.env` 权限：必须运行进程 owner = .env owner；Docker 内用 `/app/.env`
- 已 setup 系统二次打开：`users` 非空 OR `system_settings.setup_completed_at` 非空 → 全 403
- Seed 失败：返回失败明细，允许重试单个 set
