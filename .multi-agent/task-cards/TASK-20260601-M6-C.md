## Goal

让 dashboard 在未登录时跳 `/login`，登录后 cookie 自动随请求；401 自动尝试 refresh，失败跳 `/login`；按角色隐藏管理类按钮。

## UX 规范

1. **公开路由白名单**：`/login`、`/setup`（M7-B 预留）、`/_next/*`、`/api`（如有静态健康检查）。其余跳 `/login?next=<encoded>`。
2. **登录后**：从 `next` 参数跳回；首次登录无 `next` 跳 `/`。
3. **401 处理**：API 客户端拦截 → 调一次 `/auth/refresh` → 重试原请求；任一失败 → 清前端状态 + 跳 `/login`。
4. **登出按钮**：右上角下拉，显示 `email` + `role` 徽章。
5. **RoleGate**：admin 才能看到的 sidebar 项（如 `/settings/users`，M6 暂留 stub）。
6. **加载态**：AuthProvider 在 mount 时调 `/auth/me`，loading 期间显示骨架；不要闪一下未登录 UI。
7. **错误**：登录失败 → 顶部红条 + 输入框抖动；不要泄露"email 不存在"vs"密码错误"。

## Risks

- middleware 与 server components 鉴权双重：middleware 仅判 cookie 存在；server component 必要时再用 `/auth/me`
- CSRF token：非安全方法（POST/PUT/DELETE）从 AuthProvider 取 csrf_token 注 header
- SSR/CSR 切换造成闪烁：所有需要登录的页面用 client component 包，配合 AuthProvider loading
