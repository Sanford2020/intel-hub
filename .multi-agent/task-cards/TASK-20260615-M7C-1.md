- OpenAI 返回 token 数缺失：用 tiktoken 估算 + 标记 `usage_correction=true`
- 队列单 worker 进程：Celery `--queues=briefing,analyze,translate,backfill` 启动；Windows solo pool 同样支持
- 月预算重置时区：用 `AI_BUDGET_TIMEZONE` 切自然月
