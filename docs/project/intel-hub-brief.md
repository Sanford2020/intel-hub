# Intel Hub — 产品简报

## 一句话

面向商业情报团队的全球多源情报与资讯 **采、存、析、搜、推** 中台。

## 目标用户

- 研究者 / 分析师 — 跟踪全球议题
- 投资 / 战略 — 行业与地缘情报
- 媒体 / 内容 — 选题与素材池
- 团队 — 内部情报共享

## 商业版基础范围

| # | 功能 | 优先级 |
|---|------|--------|
| 1 | 情报源管理（RSS/API URL 配置） | P0 |
| 2 | 定时采集 Worker | P0 |
| 3 | 资讯条目存储 + 去重 | P0 |
| 4 | AI 摘要 + 标签（结构化 JSON） | P0 |
| 5 | 列表检索 + 基础过滤 | P0 |
| 6 | 商业情报工作台首页 | P1 |
| 7 | 关键词订阅告警 | P2 |

## 商业增强项

- 多租户 / 权限
- 高级图谱与实体关系
- 自动翻译流水线
- 移动端 / 推送

## 技术映射（脚手架）

| 需求 | 脚手架组件 |
|------|-----------|
| API | FastAPI `/api/v1/` |
| 采集 | Celery `workers/tasks/ingest/` |
| AI 分析 | `services/ai/` + `/prompts/` |
| 存储 | PostgreSQL + Alembic |
| 队列 | Redis |
| 前端 | Next.js `apps/web/` |
| Agent 辅助 | `services/agent/` + Agency roles |
