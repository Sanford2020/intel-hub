## Goal

`/articles` 顶部增搜索框，键入 ≥ 3 字符 debounce 300ms 触发；命中显示高亮片段 + rank；空结果空状态。

## Scope

### Allowed Changes

| Path | Purpose |
| --- | --- |
| `apps/web/src/app/articles/page.tsx` | 接入 SearchBox + 切换"搜索/筛选"两种模式 |
| `apps/web/src/components/SearchBox.tsx` | 受控输入 + debounce + 清空按钮 |
| `apps/web/src/components/SearchHit.tsx` | 高亮片段（dangerouslySetInnerHTML 渲染 ts_headline，先 sanitize） |
| `apps/web/src/lib/intel-api.ts` | 仅追加 searchArticles(q, lang) |

### Forbidden

- `backend/`、`workers/`、`services/`
- 不 sanitize 直接渲染（XSS 风险）

## UX 规范

- 输入 < 3 字符：禁用搜索 + 提示"至少 3 字符"
- Loading：保留旧结果 + 顶部进度条
- 空结果：显示"无匹配，尝试简化关键词" + 仍可点"清空回到列表"
- URL 同步：`?q=...&lang=...`，可分享链接

## Validation

```bash
npm run type-check && npm run build
# 浏览器：
# 1. 输入 "OpenAI" → 看到带高亮 <mark> 的标题/摘要
# 2. 清空 → 回到默认列表
# 3. 分享 URL 含 q → 重开页面自动搜索
```

## Risks

- ts_headline 输出 `<b>` 标签：用 `sanitize-html` 白名单 `<b><i><mark>` 三个
- 移动端键盘弹起遮挡结果：搜索框 sticky 顶部
