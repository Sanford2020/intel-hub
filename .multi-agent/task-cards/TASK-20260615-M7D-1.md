## Goal

按 ADR-07 给 `articles` 加生成列 `search_vector` + GIN 索引，扩展 `/articles` API 支持 `q` + 排序 + 高亮。

## Scope

### Allowed Changes

| Path | Purpose |
| --- | --- |
| `backend/alembic/versions/*search_vector*.py` | ALTER TABLE 加 GENERATED ALWAYS AS STORED 列 + GIN 索引 |
| `backend/app/models/article.py` | 暴露 `search_vector` Column（read-only） |
| `backend/app/modules/articles/service.py` | `search(q, lang, ...)` 使用 `websearch_to_tsquery` + `ts_rank_cd` + `ts_headline` |
| `backend/app/modules/articles/router.py` | `GET /articles?q=...&lang=zh|en|simple`；当 `q` 存在时返回 `rank` + `highlight` |
| `backend/app/modules/articles/schemas.py` | ArticleSearchHit |
| `docs/api.md` | §Articles Search |
| `backend/.env.example` | `SEARCH_DEFAULT_LANG=simple` `SEARCH_MIN_QUERY_LEN=3` |

### Forbidden

- `apps/web/**`（D-2 卡）
- 测试（D-3 卡）
- 引入新检索服务（ES/Meili）

## Validation

```bash
cd backend && alembic upgrade head
# search_vector 列存在；GIN 索引存在

curl 'http://localhost:8000/api/v1/articles?q=OpenAI&lang=simple'
# → 200 + items 含 `rank` + `highlight`
# → 排序按 rank desc

# q 长度 < 3 → 400
curl 'http://localhost:8000/api/v1/articles?q=AI'  # → 400
```

## Risks

- GIN 索引膨胀：跑完看 `pg_total_relation_size`；超过 table 50% → 改为 `title + summary` 索引
- 中文召回：simple 配置对纯中文效果差；M7-D-1 v1 接受现状，M7-D-3 报告中说明
- 大表 ALTER：4000 行可秒级；记录 EXPLAIN 到 REVIEW
