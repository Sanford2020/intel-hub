# TASK-20260601-M6-B: Protected Routes + RBAC

**Owner Skill:** Backend (Windsurf)  
**Status:** TODO  
**Depends on:** TASK-20260601-M6-A  
**ADR:** ADR-20260601-01

## Goal

Require valid JWT on all business `/api/v1` routes. Enforce `admin` / `operator` / `analyst` role matrix.

## Scope

- Dependencies: `get_current_user`, `require_roles(*roles)` in `backend/app/modules/auth/deps.py` (or `app/api/deps.py`).
- **Public (no auth):** `GET /api/v1/health`, `GET /api/v1/ping`, `POST /api/v1/auth/login`.
- **Protect:** sources, articles, alerts, briefings, archives, stats, ai, agents routers.
- **Write restrictions:**
  - `analyst`: GET only on intel modules.
  - `operator`: write on sources + alerts; read elsewhere.
  - `admin`: all routes + `POST /api/v1/auth/users` (create user).
- Return `401 Unauthorized` / `403 Forbidden` with consistent JSON error body.
- Update existing tests to use auth fixtures OR mark with dependency override — coordinate with M6-D; minimal fixture in this card if needed for router tests.

## Validation

```powershell
# No token → 401
curl -s -o NUL -w "%{http_code}" http://127.0.0.1:8001/api/v1/sources
# Expect 401

# Analyst token → GET 200, POST sources 403
# Operator token → POST sources 201/200
python -m pytest tests/test_auth.py -q -k "rbac or protect"
```
