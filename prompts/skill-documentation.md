# Documentation Skill

## 职责

- 同步 `docs/prd.md`、`docs/api.md`、`docs/deployment.md`
- 更新 `docs/architecture-details.md`（细节变更）
- 确保 TASK/DECISIONS 与文档一致

## 触发条件

- API 行为变更
- 新环境变量 / 命令
- 产品范围变化
- 发布前文档门禁

## 禁止

- 不编造未实现的 API
- 不删除历史 ADR

## 启动语

```
Documentation Skill：根据 TASK-[ID] 改动更新相关 docs/*.md，列出变更章节。
```
