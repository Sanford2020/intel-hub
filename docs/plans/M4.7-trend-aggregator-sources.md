# M4.7 — Trend Aggregator Sources (trends24 / getdaytrends / trend-calendar)

> **Master:** Cursor · **开发:** Windsurf/Cursor · **Review:** Codex  
> 状态：**已落地 v1** · 2026-05-22

## 1. 背景

老板提供 3 个公开趋势站点，用于补充 **X / Google 热搜信号**，与 Intel Hub 现有 OSINT、BestBlogs、AI HOT 形成「话题发现」层：

| 站点 | URL | 数据 |
|------|-----|------|
| Trends24 | https://trends24.in/ | 全球 X 热搜（24h 时间线） |
| GetDayTrends | https://getdaytrends.com/ | 全球 X 热搜排行 |
| Trend Calendar India | https://in.trend-calendar.com/ | 印度 X + Google 热搜 |

均无官方 RSS/API → 采用 **`source_type=trends`** HTML 快照解析（与 `hn` / `aihot` 同类）。

## 2. 落地范围（v1）

### 种子（4 条来源）

文件：`seeds/trend-aggregator-sources.json`

| slug | URL 配置 | 分类 |
|------|----------|------|
| `trends24-worldwide` | `https://trends24.in/` | social |
| `getdaytrends-worldwide` | `https://getdaytrends.com/` | social |
| `trend-calendar-india-x` | `https://in.trend-calendar.com/x` | social |
| `trend-calendar-india-google` | `https://in.trend-calendar.com/google` | financial |

### 后端

- `backend/app/modules/ingest/trends_parser.py` — 正则解析，最多 50 条/次，去重
- `pipeline.INGESTIBLE_SOURCE_TYPES` 增加 `trends`

### 入库形态

每条 trend → 1 条 `Article`：

- **title:** `{topic} (X #3)` / `(Google #5)`
- **url:** Twitter/Google 搜索链接或 getdaytrends 话题页
- **content:** 来源说明（snapshot）
- **published_at:** 采集时刻 UTC

进入现有分析 / 简报 / **M5 分类热度**（`social` / `financial`）。

## 3. 操作命令

```powershell
# 1. 导入种子
python scripts/seed-sources.py --api http://127.0.0.1:8001 --seed seeds/trend-aggregator-sources.json

# 2. 手动 ingest（任选）
curl -X POST http://127.0.0.1:8001/api/v1/sources/{id}/ingest

# 3. 或加入 fast ingest 队列（ingest-social-fast.py 已含 4 slug）
python scripts/ingest-social-fast.py --api http://127.0.0.1:8001
```

## 5. 风险与 v2

| 风险 | 缓解 |
|------|------|
| HTML 结构变更 | 解析失败 → ingest_log `failed`；OPS 健康探测可扩展 |
| trends24 重复话题 | 首次出现去重，上限 50 |
| 无 tweet 正文 | 仅话题信号；可链 X 搜索或后续 Apify 深采 |
| 合规 / ToS | 公开页低频抓取（60min）；商业部署前法务确认 |

**v2 候选：** 印历其他 region、historical trend-calendar 归档页、与 M5 `category_heat` 专用 `trend_score` 指标。
